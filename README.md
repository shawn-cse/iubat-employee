A fast, accessible, responsive, and lightweight faculty and staff directory built for the **International University of Business Agriculture and Technology (IUBAT)**. 

Engineered with **100% Vanilla HTML5, CSS3, and modern ES6+ JavaScript** with **zero third-party runtime dependencies**, **zero npm build steps**, and **zero external UI frameworks**. Delivers near-instant search and contact discovery across **605 verified campus employees**, **48 academic and administrative departments**, and **8 university faculties**.

## 2. Key Features & Architectural Highlights

### 📱 Smart Mobile Keyboard Occlusion Fix
On smartphones, opening the virtual keyboard typically consumes 40–50% of vertical screen height. Standard headers push search results off-screen:
- **Auto-Docking Hero:** When the search input is focused or typed into on mobile screens (`<= 768px`), the university hero banner automatically collapses into a **slim 52px sticky search bar**.
- **Compact Results Counter:** The directory summary allocates visible viewport height directly to result cards.
- **Smooth Auto-Scroll:** Typing automatically aligns the search bar to the top of the viewport so users immediately see employee results as they type.
- **Auto-Zoom Prevention:** Search input is styled with `font-size: 16px` on mobile, preventing mobile Safari and Chrome from jarringly zooming into the page.

### ⚡ Instant Multi-Field Client-Side Search
- Searches across **14 distinct attributes** simultaneously: Name, Designation, Department, Faculty, Section, Office Room, Phone Extension, Email Address, Mobile Number, Qualifications, Additional Responsibility, Institutional Affiliation, Present Address, and Study Leave status.
- Tokenized query matching: multi-word searches (e.g. `ismail cas` or `rezaul coordinator`) match regardless of word order.
- Debounced with `requestAnimationFrame` for smooth 60 FPS typing response.
- **URL Deep-Linking:** Supports initial query strings (`?q=rizna`, `?faculty=Engineering`, `?dept=CSE`, or `?studyleave=1`) to allow sharing direct links to specific employees, departments, or leave cohorts.
- Pressing `/` anywhere on desktop instantly focuses and selects the search input.

### 🏛️ Hierarchical Faculty & Department Filtering
- Two-tier filter system: Filter by academic **Faculty** (8 faculties) or narrow down to a specific **Department** (48 departments).
- When a faculty is selected, the department filter dynamically updates to display departments within that faculty.
- Dedicated **Study Leave** quick filter button lets students and administrators toggle between campus-active personnel and faculty abroad on research leave.

### 🎨 Modern Typography & Color-Coded Tone Cards
- **Plus Jakarta Sans:** Crisp geometric sans-serif typeface with weights ranging from 400 to 800.
- **6 Tone Variants:** Cards dynamically rotate through 6 cohesive border and tint themes (Emerald Green, Teal, Indigo Blue, Violet, Amber Gold, Rose).
- **View Toggle:** Seamlessly switch between **Card Grid View** and compact **List View** with preferences saved to `localStorage`.

### 📋 One-Click Copy & Native Web Share
- **Copy Details:** Formats employee name, role, department, room, phone, and email into clean text and copies directly to the clipboard with an animated status toast.
- **Native Web Share:** Leverages `navigator.share` on mobile devices for sharing to WhatsApp, Messenger, or SMS, with seamless clipboard fallback on desktop.

### 🛡️ Offline Resilience & Fast Caching
- Saves directory data locally to `localStorage` (versioned `iubat_employee_directory_cache_v4`) on initial load. If network connectivity drops or the user revisits offline, the directory loads instantly with a discreet notification.

## 3. Database Rebuild & Integration Architecture

The authoritative data source for the directory is the newly integrated **`iubat faculty database/`** containing `IUBAT.html` and `IUBAT_files/`.

### Source Analysis & Data Integrity Improvements

1. **Accurate Personnel Headcount:**
   - The previous `employees.json` contained 609 records, including 8 departed individuals who are no longer on the university roster (e.g., Fuad Ahmed Udoy, Iftekhar Sanwar Talukdar, Nashia Alam Liana, Mahfuz Auyon, Md. Arafath Rahman Nishat, Md. Sarowar Kamal Bhuiyan, Emtiaz Ahamed Mainul, Md.Abdul Ali).
   - The new database introduced 4 newly appointed/joined faculty members who were missing in the previous roster (`Dr. Md. Akhtaruzzaman`, `Dr. Fatema Nasrin Jahan`, `Sifat Howlader`, `Mahmudul Hasan`).
   - The verified roster now contains exactly **605 active personnel**.

2. **Resolution of Data Inconsistencies:**
   - **Name Truncation Fixed:** Resolved truncated names from the old dataset (e.g. `Professor Dr. Engr. Mohammad Abu` -> `Professor Dr. Engr. Mohammad Abu Eusuf`; `Professor Dr. Dewan Muhammad` -> `Professor Dr. Dewan Muhammad Nuruzzaman`).
   - **Degree & Title Updates:** Updated faculty records who earned doctorates (e.g., `Md Shafiqul Islam` -> `Dr. Md. Shafiqul Islam`; `Md Saiduzzaman` -> `Dr. Md. Saiduzzaman`; `Moniruzzaman Bhuyan` -> `Dr. Md. Moniruzzaman Bhuyan`). Corrected typos (`Drs. Sadiya Akhter` -> `Dr. Sadiya Akhter`).
   - **Canonical Department Normalization:** Standardized uppercase names (e.g. `OFFICE OF THE REGISTRAR` -> `Office of the Registrar`), fixed backtick typos (`Proctor`s Office` -> `Proctor's Office`), and normalized spacing (`UEEU-KBAD`).
   - **Affiliation Extraction:** Separated external institutions from department names for Adjunct Research Fellows (e.g. `Universiti Sains Malaysia`, `University of Leicester Business School`).
   - **Study Leave Tracking:** Extracted study leave statuses (62 faculty members) into dedicated flags and visual badges.

3. **Portrait Optimization & Sync:**
   - All 593 portrait images from `iubat faculty database/IUBAT_files/` were converted into high-performance, responsive WebP assets (`assets/images/emp-001.webp` through `emp-605.webp`) using LANCZOS resampling and quality compression.
   - For 12 personnel with institutional placeholder avatars, high-contrast dynamic SVG initials avatars are served.

### Rebuilding the Database

To rebuild or refresh the database from `iubat faculty database/IUBAT.html`:

```bash
python scripts/rebuild_database.py
```

This automated script performs data extraction, canonical normalization, portrait WebP conversion, and atomic updates to `data/employees.json`.

## 5. Developer Commands & Local Execution

Because modern browsers enforce CORS security on `fetch()` calls when opened via the `file://` protocol, serve the project folder using any static web server:

### Option 1: Python Built-in Server (Recommended)

```bash
# Start local server on port 8088
python -m http.server 8088
```
Open your browser and navigate to: **`http://localhost:8088/`**

### Option 2: NPM / Node.js Scripts (Zero Dependencies)

If you have Node.js / npm installed:
```bash
# Start dev server
npm start

# Run database & asset verification test suite
npm test

# Rebuild database from source HTML and convert portraits
npm run rebuild

# Export clean UTF-8 CSV spreadsheet
npm run export:csv
```

### Option 3: VS Code Live Server Extension

1. Open the `iubat-employee-main` folder in **VS Code**.
2. Right-click [`index.html`](file:///d:/001_LO/Coding/iubat-employee-main/index.html) and select **Open with Live Server**.

### Option 4: Docker / Nginx Container

```bash
docker run --rm -p 8088:80 -v $(pwd):/usr/share/nginx/html:ro nginx:alpine
```
