## ✨ Key Features

- ⚡ **Instant Multi-Field Search:** Real-time tokenized search indexing names, designations, departments, rooms, extensions, emails, phones, and academic study leave status.
- 🏢 **Department Filtering with Member Counts:** Clean, searchable department selector with live headcount badges for every campus division.
- 📱 **Mobile Keyboard-Aware Docking:** When searching on mobile screens, the search bar smoothly docks at the top so results remain 100% visible above virtual keyboards.
- 📇 **Modern Tone-Coded Profile Cards:** High-resolution WebP portraits, quick "View profile" modal, one-click clipboard copy, and native mobile web sharing.
- 🛡️ **Offline Resilience:** Client-side caching (`localStorage`) enables instant re-loads even under slow or disconnected campus networks.
- 🚀 **Zero Dependencies:** Pure web standards with sub-millisecond response times.

## 💻 Quick Start

Because modern browsers enforce CORS security on `fetch()` calls over `file://`, serve the directory using Python's built-in server:

```bash
# Start local server on port 8088
python -m http.server 8088
```

Open your browser at: **`http://localhost:8088`**
